# การวิเคราะห์โครงสร้างองค์กร MTEC

วิเคราะห์โครงสร้างองค์กรของ MTEC เทียบกับ BIOTEC, NECTEC และ NANOTEC ตามผังที่มีผลบังคับใช้ 1 ธันวาคม 2569 พร้อมข้อเสนอปรับโครงสร้างสำหรับ MTEC

## ไฟล์ในโปรเจกต์

| ไฟล์ | เนื้อหา |
|---|---|
| [index.html](index.html) | หน้าสรุปการวิเคราะห์: เปรียบเทียบ 4 ศูนย์ จุดแข็ง จุดที่ควรปรับ ข้อเสนอ และแผนดำเนินการ |
| [orgchart.html](orgchart.html) | ผังองค์กร MTEC ฉบับเสนอ สลับดูกับโครงสร้างปัจจุบันได้ |
| [center.pdf](center.pdf) | โครงสร้างองค์กรศูนย์แห่งชาติ (ผังทางการ 4 ศูนย์) |
| [org-comparison-4-centers.xlsx](org-comparison-4-centers.xlsx) | ตารางเปรียบเทียบจำนวนหน่วยงาน รายชื่อหน่วยงาน 129 หน่วย และการเทียบหน้าที่ |

## การเปิดดู

เปิด `index.html` ในเบราว์เซอร์ หรือเปิด GitHub Pages ของ repository นี้ (Settings › Pages › Deploy from a branch › `main` / root)

## ข้อจำกัด

- ตัวเลขนับจากกล่องในผังโครงสร้าง ยังไม่รวมข้อมูลบุคลากรและงบประมาณ
- หน้าที่ของงาน SAPD (ความร่วมมือระหว่างประเทศ) และ ESS (เทียบเท่างาน EQS ของศูนย์อื่น) ได้รับการยืนยันจาก MTEC เพิ่มเติมจากผัง
- เป็นข้อเสนอเพื่อประกอบการพิจารณา ไม่ใช่ผังโครงสร้างที่ได้รับอนุมัติ
